# Fishing Toolkit

A personal field guide to fly fishing the Eastern Sierra: spots, species, techniques, hatches, gear, and reports. Maintained by [@EvolvingSysadmin](https://github.com/EvolvingSysadmin).

Read it at [fish.ryanheavican.com](https://fish.ryanheavican.com) or browse the Markdown in [docs/](docs/index.md).

## Build locally

```
pip install -r requirements.txt
mkdocs serve
```

Then open <http://127.0.0.1:8000>.
